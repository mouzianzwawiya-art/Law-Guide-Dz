LAW GUIDE — PWA FIXED VERSION

This version is prepared for GitHub Pages at:
https://mouzianzwawiya-art.github.io/Law-Guide-Dz/

PWA fixes included:
- Manifest uses relative paths (./) so it works inside the GitHub Pages repository folder.
- Service Worker is registered as ./sw.js with scope ./.
- Old /Law-Guide/ paths removed from PWA configuration.
- Manifest link points to manifest.json.
- PWA cache version bumped to v9.
- 192x192 and 512x512 PNG app icons replaced with a Law Guide justice-scales icon.

IMPORTANT AFTER UPLOAD:
1. Replace the files in the GitHub repository with all files from this ZIP.
2. Open the site once in Chrome and wait a few seconds.
3. If Chrome still shows the old PWA/install error, remove the old Law Guide site data / old installed shortcut from the phone, close Chrome, reopen it, and visit the site again.
4. Then use Chrome > menu > Installer.

Do not use "Créer un raccourci"; that is only a Chrome shortcut and is not the standalone PWA installation.
